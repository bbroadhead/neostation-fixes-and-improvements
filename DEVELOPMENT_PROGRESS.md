## Implementation

- The common artwork panel uses one NeoGlass surface for Dynamic and omits the wheel. Stacked and Fan lead with the wheel or cover and deduplicate file paths. Saved `rows` preferences migrate to `fan`.
- Options and the artwork gallery use the same NeoGlass styling and preferences as the game list. The Favorites divider is white and overlays the existing row bounds.
- Bumper and swipe navigation skip the standalone cover and screenshot/video tabs. The existing direct video action and background playback use the same video implementation.
- Both the artwork gallery and Settings → Scraping → Media expose Remove for assigned art. A per-ROM, per-category file records an explicit clear without deleting cached media or requiring a SQLite migration. Read-time fallback and the automatic Libretro and ScreenScraper write paths honor the marker. Selecting a new image clears it. The existing Reset to Default action permits fallback again.
- The dedicated achievements page exposes Unlocked and a refresh action, supports bumper cycling of achievement status, and retains loaded results when a refresh yields no data. Compatibility review adds trigger paging, refresh, and selection and scroll preservation during a reload.
- System definitions add hacks aliases derived from the parent's known folder names and generate a category for remaining supported emulator definitions. Existing official categories and their branding take precedence. Generated categories use parent launcher definitions and the home card uses a badged parent logo when no dedicated artwork exists. File and directory imports through a parent category recognize a hacks path. This pass does not migrate historically misfiled records. That needs verification of media paths, explicit emulator mappings, and related IDs before any reassignment.

## Heronite search

Reviewed [Heronite at 934003d](https://github.com/RafaelGoulartB/Heronite/tree/934003dedfa12130a70c5c331f559af15b2fde8e). Its current Rust implementation fetches DuckDuckGo Images HTML for a `vqd` token and then requests the undocumented `i.js` JSON endpoint. It parses Bing image-result metadata and Google result markup as fallbacks. Search normalizes whitespace, requests optional transparency and shape filters, serializes requests, and bounds each search attempt chain to 25 seconds. The three general web engines use no API key. The separate SteamGridDB section uses an optional key. The parser extracts thumbnail and original URLs and dimensions, deduplicates URLs, and falls back to the original URL when a thumbnail is missing. Its Load More can reveal more locally held results. [Search implementation](https://github.com/RafaelGoulartB/Heronite/blob/934003dedfa12130a70c5c331f559af15b2fde8e/crates/metadata/src/web_images.rs)

The GPUI art picker shows asynchronous thumbnail tiles with original dimensions when known. The image pipeline uses a URL-keyed download cache and a persistent resized-thumbnail cache. Collection confirmation saves the selected result. Confirmation downloads the original first, then the thumbnail if it fails, with a 20 MiB cap and a 25-second timeout. It checks HTTP status and the reported or detected file format, stores the file by collection game and art kind, and keeps the picker open with an error when a save fails. Its console Add/Edit picker handles directional grid navigation, A, B, the on-screen keyboard on Y, and more results on X. That picker can use the URL directly, while the collection picker stores the selected file. [Collection picker](https://github.com/RafaelGoulartB/Heronite/blob/934003dedfa12130a70c5c331f559af15b2fde8e/app/src/dialogs/web_image.rs) · [Import](https://github.com/RafaelGoulartB/Heronite/blob/934003dedfa12130a70c5c331f559af15b2fde8e/crates/metadata/src/art.rs) · [Console navigation](https://github.com/RafaelGoulartB/Heronite/blob/934003dedfa12130a70c5c331f559af15b2fde8e/app/src/dialogs/add_game/picker/console.rs) · [Image cache](https://github.com/RafaelGoulartB/Heronite/blob/934003dedfa12130a70c5c331f559af15b2fde8e/crates/images/src/lib.rs)

Heronite is GPL-3.0. The current web search uses Rust/GPUI, ureq, and JSON and HTML parsers. The interaction and download lifecycle map to Flutter and Dart without bundling the Heronite runtime. The search endpoints and markup have no published API contract and can reject requests, return challenges, or change without notice. A live request from the Steam Deck retrieved a page and a token. The follow-up returned a challenge response with no image results. The request stopped there. A decision on approving a supported provider remains open. No web search provider is enabled by this pass.
