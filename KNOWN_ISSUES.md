The pack’s DS shell passes fit validation with one stacked layout and a 100-pixel gap in melonDS DS. The installed core currently has layout cycling configured, and NeoStation preserves that preference. The split-window 3DS shell remains excluded because the installed Citra layout has no documented gap control. Native touch and physical gameplay validation remain open.

The active Flatpak configuration contains native Pegasus overrides for Gambatte GB/GBC and Genesis Plus GX Game Gear. Build 2141 could skip the selected NeoStation bezel in these cases. Build 2142 appends the original core, folder and game overrides in order, then appends the temporary NeoStation layout for supported configurations. Includes, rotation or video-driver changes, and ambiguous archive paths still keep the native layout. The native RetroArch smoke confirmed the final viewport on an isolated display. The affected GB/GBC/Game Gear configurations still need physical validation.

The NeoStation Achievements panel supports opening Guides, but the emulator is a separate process. A Flutter panel cannot be assumed visible over the fullscreen game in Steam Gaming Mode. The public Gamescope workflow documents nested compositing, without a verified NeoStation overlay and global hotkey integration. The cross-mode sidebar and live unlock event path require on-device integration and validation. [Gamescope documentation](https://github.com/ValveSoftware/gamescope)

The 2144 readiness indicator reports a preflight based on ROM hash, resolved core, account, Hardcore configuration and current frontend API health. The warning and recovery notifications likewise observe the frontend API. Live emulator session acknowledgement and submission failures still require an emulator-specific signal. Confirm account, unlock and Hardcore continuity across real disc switches before closing the multi-disc phase.

The 3DS alternatives from the Retro808 archives passed stacked Citra viewport geometry checks. Their in-game screen placement and touch still need a physical test. The original two-window 3DS shell from the ci2own pack remains excluded.
