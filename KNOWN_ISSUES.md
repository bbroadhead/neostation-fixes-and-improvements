The 2141 pack audit confirmed that the original DS and 3DS shells have separate transparent windows. The picker skips them because the current RetroArch adapter uses a single combined viewport. A per-core split-screen implementation and touchscreen validation are still required. The local pack ships separately from the AppImage.

The active Flatpak configuration contains native Gambatte overrides with Pegasus overlays for GB/GBC and a Genesis Plus GX content-directory overlay for Game Gear. Where RetroArch loads one of those overrides, the existing native layout takes precedence over 2141’s selected NeoStation bezel. The picker can save a choice for those scopes, but that alone does not confirm the bezel will appear in gameplay. Supporting both requires a launch-only way to replace the layout settings while preserving native input, save, shader and core options.
