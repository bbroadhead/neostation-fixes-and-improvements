# Remaining development work

The latest session puts Visual Profiles first and requires testing and committing each phase before moving on. Phases 2–12 below also draw on the local companion plan `NeoStation — Comprehensive Development`. Existing implementations are tracked in [PROJECT_MEMORY.md](PROJECT_MEMORY.md). Keep the current behavior until its replacement is verified.

1. **Finish Phase 1 — Steam Deck Visual Profiles and console borders.** Verify the GBA viewport visually on a physical Deck and recheck Collections Back in both view styles, empty and populated collections and controller paths. Inventory all actual core and standalone assignments, validate preset performance and native override precedence, then close scaling, shader, aspect, internal resolution, reset and rollback gaps across supported emulators. Exercise the current Dolphin and five RetroArch 3D tunings with real gameplay. Cover DS/3DS touch alignment, fixed and variable orientations, hybrid and separate-screen layouts, narrow handhelds and vertical arcade. Use the provided bezel directory and review the nine requested upstream collections for formats, licensing, attribution and compatible artwork. Add permitted download/import, status, compatibility, shader dependency and collection/system filters, and report coverage by system. Verify constrained size, centering, X/Y positioning and saved per-border/per-scope placement. Take isolated backups, test Desktop and physical Gaming Mode, validate actual RetroAchievements and Hardcore sessions, then commit and package Phase 1.
2. **Consolidated artwork panel.** Add persistent Stacked (two columns), Rows (two rows) and Dynamic (default, controlled overlap) layouts for logo, cover, title screen and screenshot. Support instant switching, 1280 × 800 and larger displays, missing assets, original image proportions and manual assignments. Keep carousel icons and hero roles usable, and test every artwork surface.
3. **In-game achievement tracker and Guides.** Evaluate supported SteamOS overlay mechanisms. Add configurable keyboard/controller access, sidebar position/width/transparency, scrolling, All/Unlocked/Locked tabs, descriptions, badges, points, completion and community rarity. Refresh after unlocks. Guides should open the correct official game guide or fall back to the game page. Preserve emulator lifetime, input and gameplay, with no intentional pause. Document technical limits.
4. **Completion badges.** Cached official Perfected gold and Beaten silver markers at the upper-right of icons, with Perfected taking precedence and a visibility setting. Handle Hardcore/Softcore and unverified states in grid, list, collections and search.
5. **Connection notifications.** Deduplicated disconnect and recovery notifications with an opt-out, distinguishing network/service, auth and emulator-session failures where observable. Keep native notifications and avoid promising retroactive unlocks.
6. **Multi-disc verification.** Test grouping, playlists, formats including CHD, disc-specific hashes, switching without emulator termination, saves/progress, achievement continuity and Hardcore.
7. **Dedicated compatibility review.** Replace the generated Collections destination with the final home button, visible by default with a toggle. Include unmatched games, current and official supported hashes, revisions, status, search/filter/sort/copy and official links. Prefer USA, English Europe, English World and verified English translations in that order. Exclude non-English-only by default and show “No verified English-compatible hash found” where applicable. Surface unverified games and retain user collections. Review and integrate the separate GD-ROM fix and post-replacement verifier after branch and test reconciliation. Use only official links and verified hashes.
8. **Achievement-ready launch indicator.** Asynchronously check hash, set availability, core, account, Hardcore and connectivity. Distinguish Verified, Warning, Not Supported, Checking and Unable to Verify. Keep launches available and promptly verify actual sessions where possible.
9. **Scrape reliability and metadata.** Validate live provider combinations and bulk results across restart, including ScreenScraper auth/403/429, safe worker scaling, retry/backoff/jitter/cancellation, cache reuse and duplicate request avoidance. Complete durable failure history and per-field source tracking, configurable priority, confidence-aware match selection, metadata editing and reconciliation, and an authorized manuals source plus Open Manual. Check manual match replacement/reset, legacy imported images and safe migrations. Test no-set catalogue, provider outages, regional variants, translations and hacks.
10. **Manual search parity.** Confirm immediate in-place results across enabled providers, source/category and provider filters, loading/status, partial/alternate title suggestions, region and console disambiguation, pagination where supported, detailed previews and controller-driven refinement.
