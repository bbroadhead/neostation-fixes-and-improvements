## Decisions and requirements

- **Visuals.** Sharp & Clean is the preferred preset, with Enhanced, Authentic and Custom also available. Favor sharp scaling, correct proportions and full gameplay visibility. Use integer scaling when sensible and sharp fractional scaling otherwise. Prefer lightweight shaders and optional LCD/CRT effects. Treat 3D internal resolution separately from the viewport, especially for PSP. Fit gameplay inside the border opening even if that means shrinking it. Decorative edges may be cropped. Support portrait, vertical arcade and dual-screen arrangements with a safe fallback. Preserve controller behavior, latency, frame pacing, Hardcore, native configs and automatic launch behavior. Resolve game, core and system preferences with persisted overrides and restoration of inherited settings.
- **Bezels.** Owner-provided source is `assets/images/bezels/` under `/home/deck/neostation-stable-integration`. The checkout contains 39 PNG/INI pairs and macOS metadata. The local installer copies the pairs into NeoStation’s dedicated pack directory alongside Flatpak RetroArch. The original art is by ci2own and stays local because redistribution permission is unverified. The antique TV preset is excluded. See [handheld bezel setup](docs/HANDHELD_BEZELS.md).
- **Artwork.** Grid cards show the chosen cover with preserved aspect ratio and a defined missing-cover placeholder. Give cover, title screen, screenshot, icon, logo and hero independent slots. Current composite carousel prioritizes the cover, keeps logo clear of other artwork and skips missing media. Game lists use a larger, non-overlapping icon and a divider after the last favorite instead of inline hearts. Maintain separate displayed title, scrape title and ROM path. Manual overrides are per ROM path and category and survive refreshes, force-scrapes and restarts until explicitly replaced or reset.
- **Automatic media priority.** November 22 SteamGridDB instructions take precedence over the earlier RetroAchievements-first and integration-era NeoAssets-first orders. Current source tries SteamGridDB → hash-verified RetroAchievements → Libretro → NeoAssets → ScreenScraper per missing asset. Honor enabled providers, accept only valid category-appropriate assets, prefer the first valid cover deterministically, preserve cache and manual assignments, and isolate provider failures. Manual search gathers candidates across enabled sources, with labels and per-category selection, including Logo. The earlier request that RetroAchievements be “top priority” in the gallery leaves manual candidate presentation order unspecified after the subsequent automatic-priority change.
- **Scraping and metadata.** Preserve staged Apply/Cancel, reset and custom import, reusable remote thumbnails, submitted-title search and manual match persistence. Provide a resumable, cancellable full-library scrape with meaningful counts, category-level errors and missing-only retries. Track provenance and avoid needless re-downloads. Guard ambiguous title/region/revision/hack/translation and multi-disc matches. Keep persisted credentials separate by provider, put ScreenScraper Login between SteamGridDB and ScreenScraper developer settings, and show validation results in the UI. Preserve account-limited worker controls. Distinguish auth, throttling, malformed data, network and transient service errors. Details should make available metadata, file information, user edits, play history and verified achievements readable and copyable where applicable.
- **Achievements.** Web API auth in NeoStation and emulator gameplay sign-in are separate. Verify identity using platform-appropriate ROM hashes and official supported hashes. A manual association never establishes achievement eligibility by itself. Distinguish supported, unsupported hash, zero achievements and unverified. Keep credentials and library inventories private. Preserve verified manual mappings on recheck. The newer roadmap moves generated compatibility review out of Collections into a dedicated home destination. The existing generated collection and reason filters remain implemented until that migration.
- **Library/navigation.** Preserve one-ROM and folder imports in place, duplicate safeguards, custom systems and inherited hacks metadata/launch behavior with separate categories. Arduboy has a dedicated home card even when empty. Keep Collections Back visible and controller-reachable in grid/carousel and populated views. Settings must remain visible regardless of discovery tab toggles. Preserve working Gaming Mode input and test Desktop Mode shoulder mapping independently.

## Open interpretation

Sharp & Clean is the explicit default preset. The current preview leaves existing systems disabled until opt-in to preserve native presentation. Confirm first-run/default enablement semantics before changing existing profiles. The local comprehensive roadmap calls for a four-image artwork panel, while earlier carousel requirements explicitly include a game icon and optionally a hero.
